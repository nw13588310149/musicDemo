# 智能视唱 · 调试面板参数说明

> 适用对象：音乐老师、测试同学、现场调机人员  

## 1. 调试面板是干什么的？

智能视唱在跟唱时会做三件事：

1. **听**：麦克风采集你的声音，算出当前音高  
2. **比**：把你的音高和谱面参考音对比，算偏差  
3. **分**：每个音符给一个分数，最后汇总成总分  

调试面板里的滑条，就是用来微调「听、比、分」这三条链路的。  
改完**立即生效**，并且会**保存在本机**（下次打开 App 仍然有效）。  
点底部 **「复位」** 可恢复全部默认值。

**如何打开：** 智能视唱页右上角 **设置（齿轮）** → 弹出右侧调试面板。

---

## 2. 先认识几个词（不用背，后面会反复用到）

| 术语 | 通俗解释 |
|------|----------|
| **cents（音分）** | 音高偏差的单位。100 cents = 半音。偏差 ±50 cents 大约就是「差半个音左右」。 |
| **ms（毫秒）** | 时间单位。1000 ms = 1 秒。 |
| **RMS / 振幅** | 麦克风收到的声音「有多响」。数值越大，声音越大。 |
| **置信度** | 系统对「这次检测到的音高靠不靠谱」的把握，0~1，越高越可信。 |
| **八度归一** | 唱对音名但差一个八度（如该唱 C4 却唱了 C5）时，仍可能算「音准接近」。关闭后变成严格比对。 |
| **串音** | 扬声器外放的伴奏被麦克风又录进去，系统误以为是学生在唱。 |
| **YIN / 自相关** | 两种算音高的算法；YIN 为主，算不出来时用自相关兜底。 |

---

## 3. 顶部「实时监控」怎么看？

跟唱过程中，面板上方会显示当前一帧的检测情况（便于判断该调哪一项）：

| 显示项 | 含义 | 正常时大概什么样 |
|--------|------|------------------|
| **你的音** | 当前识别到的音名 + 频率（Hz） | 跟唱时应有稳定音名，不是 `--` |
| **参考** | 当前时刻谱面参考音 | 应和该唱的音一致 |
| **伴奏** | 当前扬声器正在播放的钢琴音（有伴奏时） | 考试模式/无声跟唱时多为 `--` |
| **偏差** | 你相对参考音偏了多少 cents | 越接近 0 越准，如 `+12c`、`-8c` |
| **置信** | 本帧音高检测置信度 | 一般 > 0.4 较可靠 |
| **振幅** | 麦克风响度（归一化后） | 正常说话/演唱约 0.02~0.15 |

## 4. 参数分组说明

下面按面板上的三个区块列出**每一项**。  
标注 **【面板无提示】** 的是界面上没有灰色小字说明、本文重点补充的项。

### 4.1 评分 / 打分链路

决定「什么时候算你的音」「多准算得分」。

#### 麦克风延迟补偿

- **默认值：** 120 ms  
- **范围：** 0 ~ 300 ms  
- **干什么：** 手机/平板从「你出声」到「系统听到并打分」有延迟。这个值把评分时间**往前挪**，让打分和实际演唱对齐。  
- **怎么调：**  
  - 感觉「明明唱准了却显示偏晚、不得分」→ **调大**（如 150~200）  
  - 感觉「还没唱到那个音就提前判分了」→ **调小**  
- iPad 外放 + 麦克风同时用时，往往要略大一点。

#### 提前演唱窗口 【面板无提示】

- **默认值：** 150 ms  
- **范围：** 0 ~ 300 ms  
- **干什么：** 某个音符**还没正式开始**，但你已经提前开唱，只要在窗口内，声音仍算在这个音符上。  
- **通俗理解：** 「允许抢拍多少」。  
- **怎么调：**  
  - 学生习惯抢拍、老被判 miss → **调大**  
  - 抢拍太严重、分数虚高 → **调小**  
- **注意：** 这不是节奏分，只是决定「这一声算哪个音」。

#### 延迟离音窗口 【面板无提示】

- **默认值：** 180 ms  
- **范围：** 0 ~ 400 ms  
- **干什么：** 音符**已经结束**，你拖尾还在唱，只要在窗口内仍算在该音符上。  
- **通俗理解：** 「允许拖尾多少」。  
- **怎么调：** 与提前窗口类似；拖尾长的学生可适当调大。

#### 命中容差 (Good)

- **默认值：** 90 cents  
- **范围：** 30 ~ 200 cents  
- **干什么：** 偏差在这个范围内，该音符算 **Good（80 分）**，并计入「命中率」。  
- **建议：** 专业视唱 60~80；普通课堂 90~120。

#### Perfect 容差 【面板无提示】

- **默认值：** 45 cents  
- **范围：** 15 ~ 90 cents  
- **干什么：** 偏差 ≤ 此值 → **Perfect（100 分，准神）**。  
- **怎么调：** 越小越难满分。严格考试可降到 30~40。

#### OK 容差 【面板无提示】

- **默认值：** 130 cents  
- **范围：** 60 ~ 240 cents  
- **干什么：** 偏差在 Good 和 OK 之间 → **OK（55 分，及格）**；超过 OK 容差 → miss（0 分）。  
- **关系：** 三档阈值从小到大是：**Perfect < Good < OK**。  
- **怎么调：** OK 越大，越容易拿部分分；越小越严格。

#### 严格音域（关闭八度归一）

- **默认：** 关闭（即开启八度归一，唱错八度仍可能得分）  
- **打开后：** 必须唱在正确八度，唱高/低八度直接 miss。  
- **适用：** 视唱考试、高年级训练。

**打分档位速查（默认容差下）：**

| 档位 | 偏差条件（约） | 单音得分 |
|------|----------------|----------|
| 准神 Perfect | ≤ 45 cents | 100 |
| 优秀 Good | ≤ 90 cents | 80 |
| 及格 OK | ≤ 130 cents | 55 |
| 不及格 miss | > 130 cents | 0 |

> 每个音符最终取得分，是该音符时间段内所有有效采样音高的**中位数**再比对参考音得出的，不是「某一瞬间」说了算。

### 4.2 实时音高 / YIN

决定「麦克风听到的声音，能不能、怎样被识别成音高」。

#### 最低 RMS

- **默认值：** 120  
- **范围：** 40 ~ 800  
- **干什么：** 声音太轻（RMS 低于此值）直接当「没唱」，不输出音高。  
- **怎么调：** 教室吵 → **调高**；学生轻声唱 → **调低**（如 80~150）。

#### 帧最低置信度 【面板无提示】

- **默认值：** 0.40  
- **范围：** 0.15 ~ 0.85  
- **干什么：** 单帧 YIN/检测结果的置信度低于此值，视为「本帧无可靠音高」。  
- **怎么调：**  
  - 音高乱跳、误识别多 → **调高**（如 0.5~0.6）  
  - 经常检测不到、轨迹断断续续 → **调低**（如 0.3~0.35）

#### 自相关最低置信度 【面板无提示】

- **默认值：** 0.24  
- **范围：** 0.15 ~ 0.70  
- **干什么：** YIN 失败时，用自相关算法兜底；相关度低于此值则仍判无音高。  
- **怎么调：** 与「帧最低置信度」类似；一般**略低于**帧置信度即可。

#### 稳定帧数

- **默认值：** 2 帧  
- **范围：** 1 ~ 6 帧  
- **干什么：** 连续多少帧音高接近，才认为「稳定在一个音上」，减少上下乱跳。  
- **怎么调：** 1 = 最灵敏但最抖；3~4 = 更稳但反应慢半拍。

#### 稳定相对差 【面板无提示】

- **默认值：** 0.08（约 8% 频率差）  
- **范围：** 0.02 ~ 0.20  
- **干什么：** 相邻两帧频率相差小于「当前频率 × 此比例」，才算「同一稳定音」。  
- **怎么调：**  
  - 数值**大** → 更容易判成稳定，轨迹更平滑，但滑音可能被抹平  
  - 数值**小** → 更敏感，细微波动也会显示

#### 平滑置信度下限 【面板无提示】

- **默认值：** 0.55  
- **范围：** 0.30 ~ 0.85  
- **干什么：** 使用「稳定平滑」后的音高时，对外展示的置信度不会低于此值。  
- **怎么调：** 一般保持默认；主要影响内部稳定性，对老师肉眼影响较小。

#### 静音重置等待

- **默认值：** 220 ms  
- **范围：** 60 ~ 600 ms  
- **干什么：** 连续静音超过此时长，清掉之前的「稳定音高记忆」。避免停顿后再开口时，还被旧音高粘住。  
- **怎么调：** 学生句间换气短、容易被旧音高干扰 → **调小**；误清空导致断轨 → **调大**。

### 4.3 人声门控 / 串音过滤

只在 **非考试模式、扬声器有伴奏** 时主要生效。  
考试模式（无声跟唱）主要靠「无声跟唱最低响度」。

#### 无声跟唱最低响度 【面板无提示】

- **默认值：** 0.012  
- **范围：** 0.002 ~ 0.05  
- **干什么：** 考试模式 / 无外放伴奏时，麦克风响度低于此值不算「有效人声」。  
- **怎么调：** 安静教室可略降；嘈杂环境略升。

#### 有伴奏最低响度 【面板无提示】

- **默认值：** 0.018  
- **范围：** 0.005 ~ 0.08  
- **干什么：** 开伴奏跟唱时，至少要这么响才进入评分（比无声模式略严，抗底噪）。  
- **怎么调：** 伴奏开很大、学生必须唱更响才得分 → 可适当**降低**；噪声大则**提高**。

#### 串音最大响度 【面板无提示】

- **默认值：** 0.075  
- **范围：** 0.02 ~ 0.20  
- **干什么：** 若检测到的音高**和正在播放的伴奏音高几乎一样**，且响度 ≤ 此值，系统认为是「扬声器串进麦克风」，**不计分**。  
- **通俗理解：** 「多小的伴奏泄漏会被当成假唱」。  
- **怎么调：**  
  - 学生轻声唱准却不得分 → **调高**（更宽容）  
  - 外放很大、不唱也有分 → **调低**

#### 串音音高窗口 【面板无提示】

- **默认值：** 10 cents  
- **范围：** 3 ~ 40 cents  
- **干什么：** 麦克风音高与伴奏音高相差 ≤ 此值，才触发「可能是串音」的判断。  
- **怎么调：** 窗口越大，越容易把「跟伴奏同音」当成串音过滤掉。

#### 强人声额外响度 【面板无提示】

- **默认值：** 0.045  
- **范围：** 0.005 ~ 0.12  
- **干什么：** 即使音高和伴奏一样，只要响度比「串音最大响度」**再高出**这一档，仍认为是学生在唱。  
- **通俗理解：** 「唱得足够响，就不会被当成扬声器」。  
- **怎么调：** 轻声唱准被误杀 → **调小**；串音误判为得分 → **调大**。

**串音过滤逻辑（简化）：**

```
如果（音高 ≈ 伴奏音）且（响度 ≤ 串音最大响度）
    → 当作串音，丢弃
否则如果（响度 ≥ 串音最大响度 + 强人声额外响度）
    → 当作真唱，保留
否则
    → 按正常规则处理
```

## 5. 常见问题 → 该调哪一项？

| 现象 | 优先尝试 |
|------|----------|
| 明明唱准了，分数低或 miss | ① 关考试模式试有无伴奏影响 ② 降「帧最低置信度」③ 升「串音最大响度」④ 升「麦克风延迟补偿」 |
| 不唱也有分 / 轨迹乱飘 | ① 升「最低 RMS」② 升「帧最低置信度」③ 降「串音最大响度」 |
| 轨迹一抖一抖 | ① 升「稳定帧数」② 略升「稳定相对差」 |
| 反应慢，光晕跟不上 | ① 降「稳定帧数」② 降「稳定相对差」 |
| 停顿后再唱，音高粘在上一个音 | 降「静音重置等待」 |
| 抢拍不得分 | 升「提前演唱窗口」 |
| 拖尾被切掉 | 升「延迟离音窗口」 |
| 分数太宽松 | 降「命中容差」、开「严格音域」、降「OK 容差」 |
| 分数太苛刻 | 升「命中容差」、升 Perfect/OK 容差 |
| iPad 外放跟唱不准 | 升「麦克风延迟补偿」、戴耳机或开考试模式、调串音相关三项 |

## 6. 复位与数据保存

| 操作 | 效果 |
|------|------|
| 拖动滑条 | 立即生效；写入本机 SharedPreferences |
| 点「复位」 | 清除所有自定义，恢复代码默认值；顶部 toast 提示 |
| 关闭面板 | 参数保持，下次跟唱继续用 |
| 重装 App | 本地调参丢失，需重新调 |

面板标题下方会显示：**「已自定义 N 项参数」** 或 **「所有参数为默认值」**。

## 7. 调试面板里没有、但和体验相关的默认值

以下参数**不在调试面板**，改代码默认值位置见 `smart_sight_singing_config.dart`：

| 配置 | 默认值 | 简要说明 |
|------|--------|----------|
| 跟唱倒计时 | 3 秒 | 点「开始跟唱」后的准备时间 |
| 旋律试听最长 | 20 秒 | 「试听旋律」自动停止 |
| 轨迹保留点数 | 720 个 | 无谱视唱拖尾长度 |
| KTV 时间窗 | 6000 ms | 无谱视唱横向可见时间范围 |
| 单音分值 Perfect/Good/OK | 100 / 80 / 55 | 与上面容差档位对应 |

## 8. 给音乐老师的使用建议

1. **课堂跟练：** 默认参数 + **考试模式（关伴奏）**，减少串音问题。  
2. **示范/试听：** 可短暂关考试模式并**戴耳机**，勿外放过大。  
3. **视唱考试：** 开「严格音域」，把 Good 容差收到 **60~80 cents**。  
4. **调参顺序：** 先看顶部实时监控 → 只动 1~2 项 → 跟唱一整句验证 → 满意再调下一项。  
5. **调乱了：** 直接点 **复位**，从零开始。
