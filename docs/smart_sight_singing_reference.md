# 智能视唱参考标准与使用方法

## 功能定位

智能视唱用于学生或老师导入 MIDI 旋律谱例后，看谱或看 KTV 音高线进行视唱，系统实时采集麦克风音高，并给出音准、命中率和综合得分。

当前功能支持两种显示方式：

- KTV 音高线：适合初学者，重点看音高走向。
- 谱例视唱：适合专业课堂，显示五线谱、四分音符、八分音符等基础时值，并叠加实唱音高轨迹。

## MIDI 标准

建议上传 `.mid` / `.midi` 文件。导入后系统会列出 MIDI 轨道，老师需要确认主旋律轨。

推荐的 MIDI 制作标准：

- 主旋律单独放在一个轨道，避免和伴奏和弦混在同轨。
- 主旋律应使用真实 note on / note off，不建议只用控制器或装饰事件。
- MIDI 速度应写入 tempo 事件；系统会按全局 tempo 解析各轨时间。
- 旋律轨建议使用常规旋律通道，避免使用 General MIDI 打击乐通道 10。
- 八分音符、四分音符等节奏由 MIDI tick 时值决定，不靠音符名称猜测。

## 评分标准

评分以确认后的主旋律轨为标准音。

音准判断：

- 默认 Good / 命中区间为 `±90 cents`。
- Perfect 默认约为 `±45 cents`。
- OK 默认约为 `±130 cents`。
- 系统按最近八度计算偏差，所以同名音跨八度不会直接判 0 分。

节奏判断：

- 音符开始前 `150ms` 内进入可计入该音。
- 音符结束后 `180ms` 内离开仍可计入该音。
- 麦克风链路默认延迟补偿为 `120ms`。

实时显示：

- 演唱中会把当前音符的临时评分计入显示，避免长音或第一颗音一直显示 0。
- 演唱结束时会重新以正式音符结果结算最终分数。

可调参数集中在：

`lib/features/smart_sight_singing/config/smart_sight_singing_config.dart`

老师认为评分过严或过宽时，优先调整：

- `defaultStandardCents`：多少 cents 内算 Good / 命中。
- `minRms`：实时拾音最低响度。
- `autocorrelationMinCorrelation`：YIN 失败后的自相关识别宽严。
- `micLatencyMs`：麦克风与播放时间线的延迟补偿。

## 真机调试面板（推荐使用方式）

页面右上角有一个圆形「调音」按钮（tune 图标），点击后会从右侧弹出
「调试面板」。这是给老师/工程师在 iPad 真机上调参用的，不会影响普通学生：

- 顶部「实时指标」实时显示当前帧的检测频率、音名、置信度、振幅、
  与标准音/伴奏音的偏差和当前命中统计；
- 中部分三组滑条：
 - 「评分 / 打分链路」：mic 延迟、提前/延迟窗口、Perfect/Good/OK 容差、
   是否启用「严格音域」（关闭后唱错八度直接 miss）；
 - 「实时音高 / YIN」：最低 RMS、帧置信度、自相关阈值、稳定帧数与
   稳定相对差、平滑置信度下限、静音重置等待；
 - 「人声门控 / 串音过滤」：无声/有伴奏的最低响度、串音音高/响度窗、
   强人声额外响度；
- 所有滑条改动**实时生效**，不需要重启演唱；
- 改动会自动持久化到 `SharedPreferences`，App 重启后保留；
- 底部「复位」清空全部本地 override；「复制 Dart 源码」会把当前 override
 拼成可直接粘贴回 `smart_sight_singing_config.dart` 的源码片段，复制到
  系统剪贴板。

推荐工作流程：

1. 在 iPad 上点击调试按钮，让老师边唱边拖滑条，找到「不再误判 / 不再过宽」
  的参数；
2. 满意后点击「复制 Dart 源码」；
3. 把剪贴板内容粘回到 `smart_sight_singing_config.dart` 中对应字段，
  作为下次发版的默认值；
4. 老师如果只是想恢复出厂默认，点「复位」即可（不会影响代码里的常量）。

## 演唱结束后的逐音详情

`finished` 阶段会在分数板下方增加一行横滚的「逐音详情」：

- 左上角统计 Perfect / Good / OK / Miss 数量；
- 每颗音的卡片显示：序号、标准音名、cents 偏差、得分；
- 颜色与谱例视图保持一致：绿(Perfect)、灰(Good)、橙黄(OK)、橘红(Miss)。

老师可以直接看出来哪几颗音偏低 / 偏高 / 完全没唱上，方便复盘。

## 页面使用方法

1. 进入「智能视唱」。
2. 点击「上传本地 MIDI」或「解析 demo」。
3. 在轨道列表中选择主旋律轨，通常选择系统标记「推荐」且音域接近人声的轨道。
4. 点击「确认轨道」。
5. 如需专业看谱练习，打开「谱例视唱」开关。
6. 可先点击「试听旋律」熟悉标准旋律。
7. 点击「开始跟唱」，倒计时结束后开始演唱。
8. 观察顶部「标准音」「你的音」「偏差」「得分」「命中率」。
9. 演唱结束后查看最终综合得分，可点击「重新跟唱」再次练习。

## 谱例视唱读法

- 黑色或深色音符为当前和后续标准旋律。
- 变浅的音符为已经唱过的音。
- 八分音符会显示旗尾，四分音符显示普通实心符头加符干。
- 谱面上的彩色点线为用户实唱音高轨迹。
- 当前竖线处若有用户音高，会显示与标准音之间的偏差连接线。

颜色含义：

- 绿色：音准在命中区间内。
- 黄色：接近标准音，可给部分分。
- 橙色：偏差较大，需要纠正。

## 常见问题

### 一直显示“识别中”，没有分数

说明麦克风检测到了声音响度，但暂时没有稳定识别出音高。

建议检查：

- 麦克风权限是否开启。
- 设备距离人声是否过远。
- 环境噪声或扬声器伴奏是否过大。
- iPad 上优先使用「无声跟唱」或戴耳机，避免伴奏串入麦克风。
- 若老师声音较轻，可适当降低 `minRms` 和 `visualOnlyMinAmplitude`。

### 老师唱对但分数偏低

建议按顺序排查：

- 是否选中了正确的主旋律轨。
- MIDI 主旋律是否比实际演唱高八度或低八度；系统已做同名音八度归一，但谱面显示仍按 MIDI 音区。
- 是否打开了外放伴奏导致串音过滤。
- 是否需要把 `defaultStandardCents` 从 `90` 调到 `100~120`。
- 是否存在明显录音延迟，可调整 `micLatencyMs`。

### 谱例节奏不对

系统按 MIDI tick 时值显示节奏。若谱例全部像四分音符，应检查 MIDI 文件本身是否把每个 note duration 都写成同样长度。

验收时建议准备一条含四分音符和八分音符的测试 MIDI，确认谱面能显示普通符干和八分旗尾。

## 教师验收清单

- 可以导入本地 MIDI。
- 可以选择并确认主旋律轨。
- 谱例视唱开关不影响原 KTV 视图。
- 谱例中四分音符和八分音符有明显区别。
- 开始跟唱后顶部能显示标准音、你的音、偏差。
- 唱准当前音时，得分不应长期停留在 0。
- 演唱结束后有最终得分、命中率和重新跟唱入口。
- 演唱结束后能看到「逐音详情」横滚条，可定位偏差最大的音。
- 点击右上角「调音」按钮能弹出调试面板；滑条改动后立即生效；
 「复位」可清掉本地 override；「复制 Dart 源码」能拼出可粘贴回 config 的片段。
